# Endogenous Associative Cognition (EAC)

This package contains:

- `endogenous_associative_cognition.tex` — theoretical paper.
- `endogenous_associative_cognition.pdf` — compile preview.
- `eac_experiment.py` — 12-experiment laptop validation suite.
- `CONFIRMATORY_PROTOCOL.md` — frozen hypotheses/statistics.
- `RUN_WINDOWS.md` — Windows PowerShell instructions.
- `requirements.txt` — dependencies.

The experiments distinguish literal replay, spontaneous associative thought, goal-directed thought, dream recombination, and durable LoRA-style consolidation.

The LoRA experiments deliberately test the key claim that an already learned distribution can be improved during an interval with no new external observations, provided internally generated practice is validated. A separate experiment tests the failure mode of unvalidated recursive self-training.
